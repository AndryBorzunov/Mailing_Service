ПРОЕКТ 4. Сервис управления рассылками

1. Созданы модели
- Dispatch - рассылка
- RecipientMail - получатель рассылки (клиент)
- Message - сообщение для рассылки
- Attempt - попытка (результат) запуска рассылки
- User - пользователь сервиса

2. Реализованы контроллеры CRUD-операций для созданных моделей

3. Все созданные шаблоны используют базовый подшаблон

4. При отсутствии авторизации отображается только главная страница.
   На главной странице отображены следующие показатели
- Общее количество всех созданных рассылок
- Количество активных рассылок со статусом "Запущена"
- Общее число клиентов в системе
- Кнопка "Вход" для авторизации пользователя
- Кнопка "Регистрация" - регистрация нового пользователя с верификацией через E-mail
- Есть возможность восстановления пароля

5. При авторизации пользователи могут создавать сообщения, рассылки, добавлять новых клиентов.
Кнопки в меню позволяют переходить на страницы сообщений, рассылок и клиентов. 
Для просмотра доступны только созданные текущим пользователем.

6. Так же есть возможность просмотра и редактирования своего профиля. Кнопка "Выход" позволяет пользователю выйти из сервиса

7. Пользователи с правами модератора могут деактивировать рассылки и блокировать пользователей.

8. Создание суперпользователя - команда **csu**
9. Создание группы "Managers" (права модератора) - команда **CreateManagersGroup**
10. Отправка рассылки - команда - команда **SendMailing**
- Так же в детальном отображении рассылки есть кнопка "Выполнить рассылку", позволяющая запустить отправку рассылки через интерфейс пользователя

11. При нажатии кнопки "Статистика" отображается страница с таблицей попыток запуска рассылок
